# board-office-skill

上市公司董办一站式 AI 技能包，覆盖董办日常核心工作流，一个 Skill 即可路由到权威数据源并完成检索、起草与归档。

## 能力模块

1. **场景路由与源能力矩阵** — 不同问题自动路由到专门的权威数据源，不堆给单一源
2. **公司治理知识库** — 制度建设、权限审批、法规问答（IMA 两层架构 + 查漏补缺）
3. **公司深度资料检索（F10 级）** — 基本情况、股本结构、股东研究、财务数据、研报评级、行情 K 线、现任董监高、历届董事会/换届、新闻与公告
4. **公告案例检索与分析** — 巨潮网 cninfo 全文检索，自动生成带原文链接的 Word 报告
5. **临时公告起草** — 数据驱动套母版生成标准格式 DOCX（样式 100% 锁定）
6. **多源交叉核对与精度控制** — 7 条硬约束 + 置信度分层
7. **大批量核查纪律** — 全量控股企业 / 公告逐家核验的三条铁律
8. **经验泛化与持续优化** — 单点发现 -> 全域覆盖，越用越强
9. **档案管理与工作区规划** — 标准化分区与文件自动归位

## 安装

- **SkillHub**：在 SkillHub「发布新技能 -> 从 GitHub 导入」填入本仓库地址即可。
- **手动**：将本仓库克隆 / 下载到 AI 助手的 skills 目录，例如 `~/.workbuddy/skills/board-office-skill/`。

## 环境准备

```bash
pip install python-docx lxml
```

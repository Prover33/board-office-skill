# 公司治理知识库搭建与维护方法论

> 本文件定义董办专家的"公司治理知识库"搭建、查询、维护全流程。IMA 知识库是让专家"懂你家公司内部规定"的核心——建得越厚越精准。

## 两层知识架构

```
用户提问 → L1 制度层（公司自有制度）→ L2 法规层（法律法规补充）
```

| 层级 | 内容 | 优先级 | 来源 |
|------|------|--------|------|
| L1 制度层 | 公司现行制度文件 | 第一优先 | 公司内部制度目录 |
| L2 法规层 | 公司法、证券法、证监会规章、交易所规则 | 制度未覆盖时启用 | 外部法规文件 |

## IMA 上传结构

```
知识库：公司治理（<KB_ID>）
├── 治理问答手册.md  ← 唯一索引文档（导航层），合并了所有清单、总图、缺口分析
├── L1 制度层/       ← 公司现行制度原文
└── L2 法规层/       ← 分批次上传
    ├── 第一批：一本通 + 核心法律 + 证监会规章 + 交易所规则
    └── 第二批：公告格式指南等工具书
```

**关键原则**：
- **一本通最优先**：解读版比原文更易被检索理解
- **民法典不传**：太泛太长，与治理关联度低，会严重稀释检索质量
- **只传必要的公告格式**：挑常用的传，其余极少涉及的不传
- **单一索引文档**：治理问答手册为唯一索引文档，不传额外的"总图/清单/目录"类 md，避免检索冲突
- **分批上传**：第一批测试 OK 后再加第二批

## 回答逻辑

1. **先查制度**：在 L1 公司制度中查找，找到则引用制度条款
2. **制度无 → 查法规**：制度未覆盖时查找 L2 法规，引用法条并说明"公司制度未约定，但依据 XXX 法第 X 条规定……"
3. **均无 → 明确告知**：两层均未覆盖时，明确告知"该事项在公司制度及相关法规中均未找到明确规定，建议咨询外部法律顾问"

## 工作流

### 场景一：搭建知识库（首次）

1. 盘点公司现行制度文件，列出完整清单
2. 编写「治理问答手册.md」作为唯一索引文档（含：治理领域关键词 + FAQ + 制度清单 + 缺口分析 + 法规目录）
3. 按结构分批上传到 IMA
4. 测试关键问题，确认回答准确性

### 场景二：更新知识库（制度修订后）

1. 将修订后的制度文件重新上传到对应文件夹
2. 同步更新「治理问答手册.md」中对应章节
3. 测试关键问题确认准确性

### 场景三：回答治理问题

1. 先通过 IMA 知识库搜索 L1 公司制度
2. 制度未覆盖时搜索 L2 法规层
3. 综合两层信息给出完整回答

### 场景四：查漏补缺回写（需用户确认）

当发现知识库存在缺口且缺失内容已从权威源核实时：

1. **用户确认**：展示拟写内容与落点，请用户明确同意；未获同意前不得执行任何写入
2. **凭证确认**：写回前检查 IMA OpenAPI 凭证已配置，缺失则中止并提示用户去 `https://ima.qq.com/agent-interface` 获取
3. **内容定型**：仅回填已核实内容。新文件走 `create_media` → COS 上传 → `add_knowledge`；对既有索引文档的补充走 `append_doc`
4. **结构守纪**：遵守既有结构——治理问答手册为唯一索引文档，不得另传"总图/清单/目录"类 md；制度进 L1、法规进 L2
5. **保密与时效**：内部管控信息仍须私有；法规/制度有修订时优先更新原文件而非新增重复条目

## ⚠️ 体系边界（国资控股公司特别注意）

国资控股上市公司同时受**两套不同治理体系**约束：

| 维度 | 国资体系 | 上市公司治理层面 |
|------|---------|----------------|
| 核心问题 | "这个事需要谁审批？" | "这个事怎么做？法规怎么规定？" |
| 决策链 | 按公司实际（如：党委会→集团→上级党组织→国资监管机构） | 股东大会→董事会→专门委员会 |
| 法规体系 | 企业国有资产法、12号令、32号令、36号令等 | 公司法、证券法、证监会规章、交易所规则 |

**本知识库仅覆盖上市公司治理层面**。涉及国资体系审批流程的问题，应引导用户查询权限指引手册。

## 问答手册编写要点

- 按治理领域分章节（如：董事会运作、独立董事、关联交易、对外担保、信息披露等）
- 每章含：关键词、常见问题、制度条款引用、法规补充
- 嵌入丰富的同义词提高检索命中率
- 附"缺口分析"章节——列出 L1/L2 均未覆盖的问题及建议补充内容

## 注意事项

1. **保密要求**：制度文件含内部管控信息，知识库需设置为私有
2. **法规时效**：定期（至少每年一次）检查法规版本是否为最新
3. **制度同步**：制度修订后及时更新至知识库
4. **关键词优化**：检索基于语义，手册中嵌入丰富关键词和同义词提高命中率
5. **不重复上传**：治理问答手册是唯一索引文档，不要上传额外的"总图""清单""目录"类文件
